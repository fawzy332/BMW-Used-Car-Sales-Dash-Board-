BMW Used Car Sales Dashboard
📘 Project Overview

This project analyzes BMW used car sales data sourced from Kaggle, using Microsoft Excel to explore trends and insights. The goal was to transform raw data into an interactive dashboard that reveals sales patterns across different regions, model types, years, engine sizes, and fuel types.

🧹 Data Preparation

The dataset was cleaned and prepared in Excel by:

Removing duplicates and fixing formatting inconsistencies

Handling missing values

Standardizing columns for accurate analysis

📊 Analysis & Techniques

Several Excel features were used to build this dashboard:

Pivot Tables: To summarize key metrics such as total sales and sales by category

Slicers: To filter data dynamically by body type, region, and fuel type

Charts & KPIs: To visualize trends and highlight total sales performance

💡 Key Insights

Regular Series models account for 82% of sales, while M cars make up 18%.

Asia leads with 34% of total sales, followed by North America and Europe.

SUVs dominate the used market, with Sedans and Sports Sedans following.

Hybrids are more popular than EVs in the used market.

Diesel has the weakest demand, reflecting global trends.

✅ Recommendations

Expand SUV offerings and highlight hybrid options.

Strengthen marketing in Asia, the top-performing region.

Introduce incentives for EVs to encourage adoption.

Reduce focus on diesel models due to low demand.

🛠️ Tools Used

Microsoft Excel – for cleaning, analysis, and visualization

Kaggle – as the dataset source
